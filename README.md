# Hishi057-notes

ポートフォリオを置いたり勉強した内容をまとめて後から見返すためのリポジトリ。

## 編集方法(自分用)

`npx quartz build --serve` でローカルサーバー起動

## プロンプト (tex文字起こし用)

画像の番号を振った数式を文字起こしして
チャット上に数式をレンダリングして、かつその下にコードブロックで囲んで生のtexも出力してください。
以下、出力例を示します。

①
AIによる実際のレンダリング

```txt
$$
tex 数式
$$
```

※ただし複数行の場合、以下のように出力して

```txt
$$
\begin(aligned)
tex 数式
&=…
\end(aligned)
$$
```
