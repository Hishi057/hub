コンピュータと外部ハードウェアの仲介を行うハードウェア。
外部装置を抽象化することによって、CPUはハードウェア固有の操作を追う必要が無くなる。

## 方式

**メモリマップトI/O** メモリの特定のアドレスを、通常の命令loadやstoreを通して、ハードウェアの入出力や状態取得などに用いる。こっちが主流。
**ポートマップトI/O** I/O専用のアドレス空間を持つ

## UART

シリアル通信(一方向通信)の機能を持ったI/O機器でよく使われる回路、ハードウェア。

| レジスタ | オフセット | 役割 |
|--------|-----------|-----|
| RHR | 0 | 受信した命令を取り出す |
| THR | 0 | 送信したい文字を書き込む |
| IER | 1 | 割り込みを有効・無効にする |
| FCR | 2 | FIFOバッファを管理する |
| LCR | 3 | 通信設定を行う |
| LSR | 5 | 受信・送信の状態を調べる |
(一部のみ掲載)

```c
#define LSR_RX_READY (1 << 0)
#define LSR_TX_IDLE  (1 << 5)

// 読み込み
static int uartgetc(void) {
    if (ReadReg(LSR) & LSR_RX_READY) {
        return ReadReg(RHR);
    } else {
        return -1;
    }
}

// 書き込み（ポーリング方式）
static void uartwritec(char c) {
    while ((ReadReg(LSR) & LSR_TX_IDLE) == 0)
        ;

    WriteReg(THR, c);
}
```

## ハードウェア：DMA

DMA(Directly Memory Access)とは、CPUを介さずにデバイスからメモリへアクセスするハードウェアである。
技術的には、メモリへアクセスする際に一定の待機時間が発生する。ここで必要な諸データのみをCPUからDMAへ渡すことによって、メモリアクセスの残りの処理を外注して、その間にCPUが他の作業が行えるという仕組みである。

## コンソール入出力

`read`や`write`関数は内部的に、その対象によって異なる関数を呼び出している。
つまり、ユーザがI/O機器によって異なる処理を行う必要はない。

特に、`devsw`構造体では、[デバイスファイル](file.md#デバイスファイル)ごとに読み書きの関数ポインタを登録することが出来る。

### バッファ

UARTの送信は基本的に遅いため、バッファを管理して、文字の読み書きを行う。
特に、書き込みバッファでは次の3変数を用いる。

| 変数 | 意味 |
|-----|------|
| r | ユーザプログラムが次に読み出す位置 |
| w | ユーザプログラムが読み出して良いデータの終端 |
| e | キーボード入力で編集中の位置 |

## VirtIO

周辺の仮想ハードウェアと通信を行う仮想OS向けに用いられる共通規格のこと。
ソフトウェアなどではなく、あくまで規格である。

### 内部実装

以下の三つのデータ構造が重要である。

| 名前 | 意味 |
| desc | 実際の処理内容(転送するデータのアドレスや長さ) |
| avail| これから処理してほしい要求 |
| used | 処理が終わった要求 |

`desc`に実際の処理内容を記述する。ただし、1つの依頼につき1つの`desc`を使うわけではなく、
複数個の`desc`を1つの依頼として考える。`desc`には`next`フィールドがあるため、そこで次の`desc`を指定している。

`avail`に、これから処理してほしい`desc`の一番初めの番号のみ記述する。

`used`に、すでに完了した`desc`の一番初めの番号のみ記述されていく。

### 具体例

"ディスクのセクタ100と101にある合計1024バイトを、RAM上の b->data にコピーする"
という操作を行うことを考える。  
この時、descの空いている要素を3つ取得して、その3つが`4`,`6`,`0`だったとする。  
各要素のそれぞれのフィールドに次のような情報を記入する。

| desc | addr | len | flags | next | 役割 |
|------|------|-----|-------|------|-----|
|desc[4]| &disk.ops[4] | 16 | `NEXT` | 6 | どこからデータを取得するか |
|desc[6]| b->data | 1024 | `NEXT` | `WRITE` | 0 | どこにデータを保存するか指定 |
|desc[0]| &disk.info[4].status | 1 | `WRITE` | 使わない | 一連の操作の状態の記入先を指定 |

ここで、`addr`とは具体的に操作内容について

次に、開始番号である`4`を`avail`に記入する。

```c
disk.avail->ring[disc.avail->idx % NUM] = 4;
disk.avail->idx++; 
```
